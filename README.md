## Selected work

### [TRACE](https://github.com/mathofdynamic/TRACE)

Repository-native change intelligence for human and AI software teams. TRACE connects change intent to implementation evidence, decisions, risks, and technical debt through portable `.trace` records. Its active pilot includes local analysis, a CLI and Agent Skill, and GitHub-connected dashboard paths. Cloud source analysis is disabled; hybrid sync is limited to policy-approved artifacts.

### [OpenUse](https://github.com/mathofdynamic/OpenUse)

A local-first, AI-agnostic Computer Use runtime for macOS and Windows. Its typed tool layer applies permission and safety checks, prefers accessibility APIs, and uses a provider abstraction. Electron and React coordinate Swift and .NET controllers. OpenUse is an MVP in active development. The macOS controller is available for local testing; Windows GUI qualification remains open.

### [SAMI](https://github.com/mathofdynamic/SAMI)

A visual design-token studio for AI-assisted product development. SAMI keeps tokens in one source of truth, previews them in application screens, and exports design specs for coding agents. It includes Persian and RTL support, with Cloudflare Workers AI integration.

### [Perfection Loop](https://github.com/mathofdynamic/perfection-loop)

An evidence-first Agent Skill for AI-assisted software development. It sets an acceptance contract, captures the real application, runs automated checks and independent reviews, tracks defects, then repeats verification after fixes. Its core rule is `implemented != verified != finished`.

### [AEO Maker](https://github.com/mathofdynamic/AEO-Maker)

A web analysis tool that maps site structure, extracts rendered page content, captures screenshots, and generates page-level AI-readable `LLM.txt` content.

### [WikiGraph](https://github.com/mathofdynamic/WikiGraph)

**Experimental / in development.** The project explores an agent-oriented empirical knowledge library with machine-readable twins, retrieval, and knowledge relationships. The current public implementation is a client-side demo backed by mock local storage; the backend is not implemented.

**More tools:** [Humanizer](https://github.com/mathofdynamic/humanizer), a Persian-first writing-quality skill, and [seo-chief](https://github.com/mathofdynamic/seo-chief), a repository-aware SEO, AEO, and GEO workflow skill with validation and release safeguards.
